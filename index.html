# Time Capsule Invitation A futuristic, interactive invitation website built with HTML, CSS, and JavaScript. ## Files - `index.html` — page structure - `style.css` — neon/futuristic visual design - `script.js` — interactive steps, code unlock, countdown, RSVP preview, calendar download ## Run Open `index.html` in a browser, or publish the repository with GitHub Pages. Demo access code: `2026` Note: RSVP is a front-end preview only and does not save responses.
